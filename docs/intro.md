## 关于本站

**wbsxhh 的 blog** — 个人技术博客，使用 [Docusaurus](https://docusaurus.io/) 构建，部署在 Cloudflare Pages。

## 博客与文档的关系

本站分为两个模块，定位不同、互相补充：

| 模块 | 路径 | 定位 | 内容特点 |
|------|------|------|----------|
| **博客** | [/blog](/blog) | 观点、思考、复盘 | 短文为主，适合快速阅读 |
| **文档** | [/docs](/docs/intro) | 博客的**详细技术补充** | 操作步骤、架构细节、参考手册 |

**阅读建议**：

1. 先从**博客**了解核心观点
2. 需要深入细节时，到**文档**查阅完整技术说明

维护者请参阅 [编写与发布新文章](/docs/blog/write-new-post)。

## 本地开发

维护者可在本地运行本站：

```bash
npm install
npm start        # http://localhost:3000
npm run build
npm run serve
```

## 技术栈

- **框架**: Docusaurus 3.x (Classic)
- **部署**: Cloudflare Pages
- **Node.js**: >= 20
