# wbsxhh 的 blog

个人技术博客，基于 Docusaurus 构建。

- **博客**：观点与思考（[/blog](/blog)）
- **文档**：博客的详细技术补充（[/docs](/docs/intro)）
- **GitHub**：[github.com/wbsxhh201771](https://github.com/wbsxhh201771?tab=repositories)

## 快速开始

```bash
npm install
npm start        # http://localhost:3000
npm run build
npm run serve
```

## 部署

详见 [docs/deploy/cloudflare-pages.md](docs/deploy/cloudflare-pages.md)。
